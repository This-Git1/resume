# Интерактивное резюме

Статический сайт, без сборки и зависимостей. Открывается прямо из файла
или деплоится на любой статический хостинг.

## Файлы

- `index.html` — разметка (трогать не обязательно)
- `style.css` — стили обоих режимов (трогать не обязательно)
- `script.js` — движок отрисовки (трогать не обязательно)
- `data.js` — **твои данные**. Единственный файл, который нужно редактировать.

## Как вписать свои данные

Открой `data.js` и замени плейсхолдеры внутри `RESUME_VERSIONS.default`:
имя, роль, контакты, опыт, навыки, проекты, образование. Структура —
обычный JS-объект, ничего компилировать не нужно.

## Постоянные ссылки на версии резюме

`data.js` может содержать несколько версий (ключи объекта `RESUME_VERSIONS`).
Уже есть `default` и `short` как пример. URL выбирает версию через параметр:

```
site.com/?resume=default
site.com/?resume=short
```

Чтобы добавить свою версию — скопируй блок `short` в `data.js`,
дай ему новый ключ, например `backend-lead`, и раздавай ссылку
`site.com/?resume=backend-lead`. Версии полностью под твоим контролем —
никакого бэкенда для этого не нужно.

Также можно сразу открыть сайт в режиме терминала:

```
site.com/?mode=terminal
site.com/?resume=short&mode=terminal
```

## Как посмотреть локально

Просто открой `index.html` в браузере двойным кликом. Либо, если хочешь
через локальный сервер (иногда браузеры капризничают с `fetch`/шрифтами
при открытии файла напрямую):

```bash
cd resume-site
python3 -m http.server 8000
# затем открой http://localhost:8000
```

## Как задеплоить

Любой из вариантов ниже — просто загрузить эти 4 файла:

- **GitHub Pages**: создать репозиторий, закинуть файлы, включить Pages
  в настройках репозитория (Settings → Pages → branch `main` / root).
- **Netlify / Vercel**: drag-and-drop папки на их дашборд — задеплоится
  за секунды, без конфигурации.
- **Свой VPS/nginx**: скопировать файлы в `/var/www/resume` и отдавать
  как статику.

## Что можно докрутить дальше (не обязательно)

- Резюме в PDF рядом со ссылкой (`<a href="resume.pdf">`)
- OpenGraph-превью для шаринга ссылки в мессенджерах
- Собственный домен вместо `*.github.io`
